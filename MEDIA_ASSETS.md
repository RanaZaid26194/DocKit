# Media assets

All assets are generated by DocKit's build process. Replace freely with
your own — just keep the filenames so the code and manifest keep working.

| File | Purpose | Where it is referenced |
| --- | --- | --- |
| `public/logo.png` (512×512, transparent PNG) | Primary brand mark. Deep-teal stylized open door. | Header on landing, header on renter flow, header on dashboard, PWA maskable icon. |
| `public/favicon.png` (512×512, opaque PNG) | Browser tab icon and small PWA icon. | Linked from `__root.tsx` head. |
| `public/manifest.webmanifest` | PWA install manifest. | `<link rel="manifest">` in root head. |

To swap the logo, replace `public/logo.png` with your own file at the same
path. No code change needed.

Generation prompts (kept for future regeneration):
- **logo.png**: "A minimal flat civic service logo for DocKit — a stylized open door in deep teal (#0f5257) on transparent background, geometric, warm and trustworthy, no gradients, no shadow, government-service feel."
- **favicon.png**: "Simple flat favicon: stylized open door glyph in solid deep teal on white background, clean geometric shapes, 512x512, no text."
